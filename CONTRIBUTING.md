# Contributing to SpecSpot

First off, thank you for considering contributing to SpecSpot! It's people like you that make SpecSpot such a great tool for finding the best mobile phones.

## How to Contribute

### Reporting Bugs
If you find a bug, please create an issue on GitHub detailing:
- What you were trying to do.
- What happened instead.
- Your environment (OS, Browser, etc.).
- Steps to reproduce the bug.

### Suggesting Enhancements
If you have an idea for a new feature or improvement:
- Check existing issues to ensure it hasn't already been suggested.
- Open a new issue explaining your idea and how it benefits the project.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure you have activated your virtual environment and installed dependencies.
3. Make your changes and test them locally using `python manage.py runserver`.
4. Make sure your code follows standard Python (PEP 8) and Django guidelines.
5. Create a Pull Request with a clear title and description of your changes.

## Development Setup
Please see the `README.md` for instructions on how to set up the project locally.

Thanks for your contribution!
